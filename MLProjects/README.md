## 📚 Projects

### 🏠 1. House Price Prediction

**Machine Learning Type:** Regression
**Algorithm:** Linear Regression
**Deployment:** Streamlit

A Machine Learning project that predicts the estimated price of a house based on:

* Area (sq ft)
* Number of Bedrooms
* City

The project uses **Linear Regression** to train the prediction model and provides a Streamlit interface where users can enter house details and receive an estimated price.

📁 **Project Folder:** `House-Price-Prediction`

---

### 🌼 2. Iris Flower Predictor

**Machine Learning Type:** Classification
**Algorithm:** Random Forest Classifier
**Deployment:** Streamlit

An interactive Machine Learning application that predicts the species of an Iris flower based on:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The project uses the **Iris dataset from Scikit-learn** and a Random Forest Classifier. The Streamlit application also displays prediction probabilities for the possible Iris species.

📁 **Project Folder:** `Iris-Flower-Predictor`
